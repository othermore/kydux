# Qué es un programa

¿Alguna vez has deseado poder decirle a un ordenador exactamente qué hacer? Un ordenador hace justo lo que se le pide, paso a paso, ¡pero necesita que le digamos cómo!

Cada paso que le damos a un ordenador es una instrucción. Una lista de instrucciones es un programa. El ordenador lee el programa de arriba abajo, haciendo cada instrucción en orden.

---
