# Your first action

Welcome to the school! I am your teacher.

Here, you make the wizard move by writing Python.
Python is a language that computers understand.

---

## Objects and actions

In Python, the wizard is an **object**.
Its name in the code is `wizard`.

An object can do things.
The things it can do are its **actions**.

To make the wizard do an action, write its name, a dot, and the action:

```python
wizard.move_right()
```

The brackets at the end mean *do it now*.
This line makes the wizard take one step to the right.

---

## Try it

Write the same line twice, and the wizard takes two steps.
Python does the lines one after the other, from top to bottom.

```python try
wizard.move_right()
wizard.move_right()
```
