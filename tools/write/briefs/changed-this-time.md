Write one sentence for each of the thirteen levels listed, in English and in Spanish: the
files listed, each holding that one sentence and nothing else, no quotes, no title.

## What the sentence is for

Each of these levels is played several times over in the game's world when the child
runs a program: the things in it are laid out in a few different arrangements, and the
program must win in every one of them. That is how the game is programmed, and the
child is never told of it: never of "ways", "arrangements", "versions", "maneras",
"formas", "variantes", nor of how many there are.

The level's `changes` text, given above in each `text.<lang>.json`, is what the level's
start card says may be different each time. Your sentence is said later, on the card
that tells how a run went. The child has run a program before and saw the level one
way; this run failed with the things laid out another way, and the picture on the
screen changed. Before the card says what went wrong (*Todavía no: …*, *¡El profesor te
ha visto!*), it says in one line of its own what is different this time, so that the
child looks at the picture and sees it.

The owner's sentence for `the-moving-key`, in Spanish, is the model, and enters as
written; write its English, and the other twelve after it:

- *Esta vez, la llave está en otro sitio.*

## How it is written

- One short sentence for a child of eight, opening with *Esta vez,* / *This time,*: the
  thing of the level's `changes` sentence, and that it is different now. It is said
  of this one run, in the present: never *cada vez*, *siempre*, *each time*, *always*.
- What the child can see or meet in the picture, in the words the level's `changes` and
  intro use for its things (*la llave*, *Dask*, *el agujero*, *las escobas del suelo*,
  *la puerta cerrada*). Where the `changes` sentence names several things (how many
  brooms and on which pegs), name them as shortly as it can be said, one thing if one
  says it (*hay otras escobas colgadas*).
- Never what the difference is in this run (nearer, further, three brooms): the same
  sentence is said for every arrangement.
- Never *manera*, *way*, *forma*, *arrangement* or a count of them; never a cell or a
  number of steps; no exclamation.
- The English and the Spanish say the same thing, each as a native speaker would.
