Pixel art for a children's 2D game in a top-down view. A single sheet on a flat pure magenta (#FF00FF) background, a strict 4 by 4 grid of square tiles of equal size, separated by thin magenta gaps. Each tile is green grass with a light brown dirt path on it, the path the same width in every tile and every path arm reaching the exact middle of the tile's edge, so that tiles join seamlessly. Row 1 (left to right): a small round patch of path with no exits; a path end going north; a path end going east; a path corner joining north and east. Row 2: a path end going south; a straight vertical path; a corner joining east and south; a T joining north, east and south. Row 3: a path end going west; a corner joining north and west; a straight horizontal path; a T joining north, east and west. Row 4: a corner joining south and west; a T joining north, south and west; a T joining east, south and west; a crossroads. Crisp pixels, no anti-aliasing, a limited palette, no text.
