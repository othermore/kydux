# Un nombre para un valor

Una biblioteca se basa en el orden. Cuando un programa usa el mismo valor en varios lugares, escribirlo de nuevo cada vez es fácil de hacer mal y difícil de cambiar.

En su lugar, puedes darle un nombre al valor una vez y usar ese nombre después. Un nombre para un valor es lo que los programadores llaman una variable.

---
## Darle un nombre a un valor

Para hacer una variable, escribes el nombre, luego un signo igual y después el valor. Escribiremos `steps = 3`. El signo `=` pone el valor bajo el nombre; no pregunta si son iguales.

Luego, ¡puedes usar el nombre `steps` donde iría el número tres, como en el argumento de un movimiento!

---
## Pruébalo

Vamos a poner un valor bajo un nombre y a usarlo para caminar. ¡Mira qué limpio y ordenado queda el código!

```python try
steps = 3
wizard.move_right(steps)
```
