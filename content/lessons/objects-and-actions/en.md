# Objects and actions

In a program, everything is an object. The characters, the things you find, a door, a book... they are all objects. Your wizard is an object too, the one we call `wizard`.

An object can do actions, which programmers call methods. Every object has its own methods. For example, `move_right` is a method of `wizard`.

---
## How to write an instruction

When you write an instruction, you put the object first, then a dot. Then comes the method, which belongs to it, and finally brackets, which tell the computer to do it right now!

There are four move methods, one for each direction, and each takes one step. We write one instruction on each line.

If you ever forget what your wizard can do, just open your notebook! It is a button on the screen that lists every method your wizard knows.
